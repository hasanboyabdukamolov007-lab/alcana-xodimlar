# Xodimlar Hujjatlari — Telegram Mini App (v2)

Professional versiya: O‘zbek (asosiy) + Русский + English.

## Hujjatlar ro‘yxati (rasmdan + testlar)

1. Xodimning shaxsiy ma'lumoti
2. Ishga olish ankеtasi
3. Pasport nusxasi
4. 3x4 rasm (8 dona)
5. INN
6. Korxona ankеtasi
7. Mehnat shartnomasi
8. Texnika xavfsizligi
9. Sudlanmaganligi haqida ma'lumotnoma
10. **16Personalities test natijasi**
11. **Mensa IQ test natijasi**

## Xususiyatlar

- To‘liq 3 tilda ishlaydi (UZ / RU / EN)
- Qidiruv (search)
- Progress bar + Complete / Incomplete holati
- Har bir hujjat uchun tick + fayl yuklash
- Telegram theme va haptic feedback
- Chiroyli mobil interfeys

## Qanday ishga tushirish

1. `index.html` ni brauzerda oching — darhol demo ishlaydi.
2. Telegram uchun:
   - Fayllarni HTTPS serverga joylang (Vercel, Netlify...)
